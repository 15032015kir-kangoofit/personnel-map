# Расстановка персонала цеха сборки (демо, PWA)

SPA на чистом HTML/CSS/JS, без сборщиков и бэкенда. Данные — в `localStorage`
(ключ `personnel-map-state-v1`). Устанавливается на телефон как PWA.

## Локальный запуск

```bash
python3 -m http.server 8000
```

Откройте http://localhost:8000. Через `file://` приложение не работает
(нужен `fetch('data/seed.json')` и service worker).

## Деплой на Vercel

1. Создайте репозиторий на GitHub и запушьте содержимое папки `personnel-map/`.
2. Vercel → **Add New → Project → Import** этого репозитория.
3. Framework Preset: **Other**, build command и output directory — пустые. **Deploy**.

## Установка на телефон

- **Android (Chrome):** меню ⋮ → «Установить приложение» (или кнопка «Установить» в шапке).
- **iOS (Safari):** «Поделиться» → «На экран Домой».

## Обновление версии

Service worker работает по схеме cache-first. После изменения любого файла
приложения увеличьте `CACHE` в `sw.js` (например, `personnel-map-v3` → `v4`), иначе у
пользователей останется старая версия.

## Заметки

- Экспорт PDF/Excel использует библиотеки с CDN (jsDelivr) и шрифт DejaVu Sans
  для кириллицы в PDF. При первом запуске нужен интернет; затем файлы кэшируются.
- Иконки PWA не добавлены намеренно: на части устройств браузер может
  предложить только «Добавить на главный экран» вместо полноценной установки.
- Состав постов и рабочих задаётся в `data/seed.json`. Данные подгружаются
  только при пустом `localStorage` (сброс: «Настройки → Сбросить смену» очищает
  табель и расстановку; для полного возврата к seed очистите данные сайта).
